# OpenBarnyard WASM

Browser build of OpenBarnyard. The game requires the user to select their own legally obtained Barnyard `Data` folder. Game data is not included in this repository.

## Deploy with Cloudflare Pages

- Framework preset: None
- Build command: leave empty
- Build output directory: `.`

Open the deployed HTTPS site, select your own `Data` folder, wait for the import, then launch the game.

Private/incognito browser windows may have reduced storage quotas and are not recommended for importing large game folders.
