## English

A browser-based version of **Barnyard**, based on [OpenBarnyard](https://github.com/InfiniteC0re/OpenBarnyard).

BarnyardWeb brings OpenBarnyard to the browser with a custom web interface and simpler game data installation.

### Features

- WebAssembly build prepared with Emscripten
- Custom browser interface
- Two ways to install game data: select a local `Data` folder or upload data through the web interface
- Persistent storage for installed game data
- Play directly in a modern browser, without a separate desktop launcher

### Play

**[Open BarnyardWeb](https://openbarnyard-wasm.pages.dev/)**

You must provide your own game data from a legally obtained copy of *Barnyard*. Game files are not included in this repository.

## Русский

**BarnyardWeb** — браузерная версия игры **Barnyard**, основанная на проекте [OpenBarnyard](https://github.com/InfiniteC0re/OpenBarnyard).

Цель проекта — перенести OpenBarnyard в браузер, предоставить собственный веб-интерфейс и упростить установку игровых данных.

### Возможности

- WebAssembly-сборка, подготовленная с помощью Emscripten
- Переработанный веб-интерфейс
- Два способа загрузки игровых данных: выбор локальной папки `Data` или загрузка через веб-интерфейс
- Сохранение установленных игровых данных между запусками
- Запуск непосредственно в современном браузере без отдельного лаунчера

### Запуск

**[Открыть BarnyardWeb](https://openbarnyard-wasm.pages.dev/)**

Для запуска необходимо самостоятельно предоставить игровые данные из легально полученной копии *Barnyard*. Игровые файлы не входят в этот репозиторий.
