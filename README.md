# Barnyard — Browser Port

[English](#english) | [Русский](#русский)

## English

An unofficial browser port of **Barnyard**, powered by [OpenBarnyard](https://github.com/InfiniteC0re/OpenBarnyard).

This project brings Barnyard to modern web browsers using WebAssembly and Emscripten, with a custom web interface and simplified game data installation.

### Features

- WebAssembly build prepared with Emscripten
- Custom browser interface
- Two ways to install game data: select a local `Data` folder or upload data through the web interface
- Persistent storage for installed game data
- Play directly in a modern browser, without a separate desktop launcher

### Play

**[Open BarnyardWeb](https://openbarnyard-wasm.pages.dev/)**

Game data can be loaded directly through the web interface or selected from a local `Data` folder. Game data is not stored in this repository.

## Русский

**Barnyard — Browser Port** — неофициальный браузерный порт игры **Barnyard**, работающий на основе [OpenBarnyard](https://github.com/InfiniteC0re/OpenBarnyard).

Проект переносит Barnyard в современные браузеры с использованием WebAssembly и Emscripten, предоставляет собственный веб-интерфейс и упрощает установку игровых данных.

### Возможности

- WebAssembly-сборка, подготовленная с помощью Emscripten
- Переработанный веб-интерфейс
- Два способа загрузки игровых данных: выбор локальной папки `Data` или загрузка через веб-интерфейс
- Сохранение установленных игровых данных между запусками
- Запуск непосредственно в современном браузере без отдельного лаунчера

### Запуск

**[Открыть BarnyardWeb](https://openbarnyard-wasm.pages.dev/)**

Игровые данные можно загрузить непосредственно через веб-интерфейс или выбрать локальную папку `Data` на компьютере. Игровые данные не хранятся в этом репозитории.
